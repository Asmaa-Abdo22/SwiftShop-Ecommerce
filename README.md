# ✨ Features 
* Authentication & Authorization: Secure user authentication with JWT and protected routes to ensure only authorized users can access certain pages.
* Responsive Design with Tailwind CSS for a seamless experience across all devices.
* JWT Authentication for secure login and account management.
* Advanced State Management using React Query for efficient data fetching and caching.
* Product Filtering & Loading are powered by Axios for API requests.
* Real-time Notifications with React Hot Toast for user-friendly alerts.
* SEO Optimization using React Helmet to improve search engine visibility.
* Interactive Image Gallery with React Image Gallery and Swiper.
* Wishlist & Cart System for a personalized shopping experience.
* Offline Detection using React Detect Offline to handle connectivity issues.

# 📄 Pages
* Home Page 🏠 – Displays featured products, categories, and offers.
* Brands Page 🏷️ – Showcases different brands available in the store.
* Categories Page 📂 – Lists products by category for easy navigation.
* Wishlist Page 💖 – Allows users to save their favorite products.
* Cart Page 🛒 – Displays selected products before checkout.
* Orders Page 📦 – Shows user order history and order details.
* Login & Register Pages 🔐 – Handles user authentication and account creation.
* Product Details Page 🔍 – Provides detailed information about each product.
* 404 Page ❌ – Displays when users navigate to an invalid URL.

# 🛠 Technologies & Libraries
* Frontend: React, Tailwind CSS
* State Management: React Query
* Routing: React Router DOM
* Form Handling & Validation: Formik & Yup
* HTTP Requests: Axios
* Authentication: JWT-Decode
* UI Enhancements: FontAwesome, React Spinners, Swiper
